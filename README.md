# Privacy Policy - AI Code Review Assistant

## Quick Summary

This extension only stores your API key locally on your device. We don't collect, store, or share any personal information or code content.

## ⚠️ Important Disclaimer

**WE ARE NOT RESPONSIBLE FOR YOUR DATA AFTER IT'S SENT TO GOOGLE GEMINI AI**

By using this extension, you acknowledge that:

- Your code content will be transmitted to Google's Gemini AI service
- Google processes this data according to their own privacy policy
- We have no control over how Google handles your data
- You are solely responsible for ensuring you have permission to share the code

## 1. Data Collection

### ❌ We DO NOT collect:

- Personal information (name, email, phone)
- Browsing history or web habits
- Analytics or tracking data
- IP addresses or location data
- GitHub account information

### 💾 We DO store locally:

- Your Google Gemini API key (encrypted in browser storage)
- Extension settings and preferences
- **Storage location:** Your device only

### 📤 Data sent to third parties:

- **Only to Google AI:** Code content when you click "AI Review"
- **Purpose:** Code analysis only
- **Control:** You decide when to send data

## 2. How We Use Information

- API keys are used solely to communicate with Google's Gemini AI
- Code content is sent to Google AI only when you explicitly request analysis
- Settings are used to customize the extension experience
- No analytics or tracking is performed

## 3. Data Sharing & Third-Party Services

We do not sell, trade, or share your data with third parties, except:

- **Google Gemini AI:** Code content sent only when you request analysis

This extension uses Google's Gemini AI API. Please refer to [Google's Privacy Policy](https://policies.google.com/privacy) for information about how Google handles data sent to their API.

## 4. Data Security

- All data stored locally using Chrome's secure storage API
- Communication with Google's API uses HTTPS encryption
- No data transmitted to our servers
- You can remove all data by uninstalling the extension

## 5. Liability Limitations

**WE DISCLAIM ALL LIABILITY FOR:**

- Data breaches or unauthorized access by Google or third parties
- Any damages arising from Google's processing of your data
- Business losses or consequential damages
- Actions taken by Google with your data

## 6. Your Rights & Responsibilities

### Your Rights:

- Remove your API key anytime through settings
- Uninstall extension to remove all stored data
- Control when code analysis is performed

### Your Responsibilities:

- Ensure permission to share code being analyzed
- Verify no sensitive data is included
- Comply with applicable privacy laws
- Check organization policies before use

## 7. User Consent

By using this extension, you explicitly agree that:

- You understand your code will be sent to Google's Gemini AI
- You have read Google's privacy policy
- You have permission to share the code being analyzed
- You accept all risks associated with data transmission
- You will not hold us liable for consequences arising from Google's data handling

## 8. Data Retention

- API keys and settings stored until you uninstall the extension
- Code content is not stored and only temporarily processed
- You can clear all data by uninstalling the extension
